THE FUNCTION V4 WAS MISSING

clean_text(s)

# ~15 lines, run per document def clean_text(s): s = unicodedata.normalize("NFC", s) s = html.unescape(s) # & र s = s.replace("�", "") # drop U+FFFD # strip ZWSP, BOM, bidi, C0/C1 s = re.sub(NOISE_RE, "", s) # KEEP U+200C ZWNJ, U+200D ZWJ s = re.sub(r"\s+", " ", s).strip() return s # hash = sha1(clean_text(s)) ← AFTER, not before
The content hash is computed AFTER cleaning, not before, so two docs that differ only in invisible junk dedupe to the same hash.
WHY IT MATTERS
Dolma is clean at the document level but NOT at the character level. V4 tokenized raw docs, so 46 garbage tokens took permanent vocab slots. clean_text() removes them once, before the tokenizer ever sees the corpus.

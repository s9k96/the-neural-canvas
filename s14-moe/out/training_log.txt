S14 · One Becomes Eight — training log
======================================
The console output of `python s14_moe.py`, verbatim, from the three invocations it took to
produce out/evidence.json. Nothing has been removed or edited; only these headers are added.

Every training run is a cached stage (out/stages/). A later invocation prints "[resume] <name>"
for a run it reloaded from that cache: it did NOT retrain it. Each run below was trained exactly
once, except clone-prob-bias, whose rerun is explained in invocation 3.

Machine: Apple M5, CPU (torch 2.2.2, python 3.9.6). Batch 32 x 256 = 8,192 tokens per step.
Progress lines print every ~1/12 of a run; the per-25-step train loss, expert loads and router
gradients for every run are in out/evidence.json.

Proof: Generalization Gap vs Dataset Size

Same architecture, same 600-point held-out test set, same number of training epochs - the only thing that changes between bars is how much data the network got to see.
Generalization gap (test − train loss)
Training set size (n)

All three networks share the exact same architecture: three hidden layers of 64 ReLU units apiece, vastly more parameters than needed for a 2-D classification boundary. Handed only 20 noisy points, that capacity does what capacity does - it memorizes every point, noise included, and train loss collapses to essentially zero. The decision boundary it draws is a tangle of tiny islands carved out just to catch the mislabeled stragglers.

The held-out test set never changes across the three runs and is drawn from the same noisy distribution. A network that memorized its 20 training points has learned nothing transferable about that distribution, so test loss stays high - the train/test gap is huge. Give the same architecture 200 points and the gap narrows; give it 2000 and the network can no longer afford to memorize idiosyncratic noise, so it falls back on the actual signal and train and test loss converge.

The more of the world we see, the less we need to memorize it.

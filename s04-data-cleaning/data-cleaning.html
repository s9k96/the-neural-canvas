04The other concern we cleaned up: Indic erasure

The dangerous failure in a cleaning pipeline is not leaving dirt in — it is quietly deleting good low-resource text with filters tuned on English. We ran both quality filters over the same Hindi documents to measure it.

Normalization keeps the zero-width joiner and non-joiner (real letters in Brahmic scripts) while stripping true noise — . Language ID detects script at runtime instead of trusting the folder, dropping mislabeled non-Hindi docs. Quality filtering treats the danda (।) as a sentence terminator and drops the English stop-word rule that would fail perfectly good Hindi.

05Why deduplication must be global

Duplication is global. We split the corpus into 4 shards, deduplicated each one locally so every shard looked clean, then ran a single global pass over all of them. The gap is the point.

06Provenance: no shard enters without a manifest

Cleaning happens before the content hash, so the hash reflects the cleaned text. Identifiers come from content, not a counter, so the same input always reproduces the same output. Every shard carries this, or it is blocked from the corpus.
